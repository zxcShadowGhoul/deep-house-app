# ДИП — PWA для iPhone и Android

Это устанавливаемая веб-версия учёта Deep House. Интерфейс адаптирован под мобильный экран, добавлены manifest, иконки, режим standalone и service worker для кеширования оболочки.

## Важно

PWA нельзя корректно установить на iPhone из локального ZIP-файла. Сначала разместите содержимое этой папки на HTTPS-хостинге (например, GitHub Pages, Netlify или Vercel). После публикации откройте HTTPS-ссылку в Safari на iPhone.

## Установка на iPhone
1. Откройте опубликованный HTTPS-адрес в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Включите «Открывать как веб-приложение», если такой переключатель отображается, и нажмите «Добавить».

## Установка на Android
Откройте HTTPS-адрес в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий.
2. Загрузите все файлы и папку `icons` в корень репозитория.
3. В Settings → Pages выберите публикацию из ветки `main`, папка `/ (root)`.
4. Дождитесь появления HTTPS-адреса и откройте его на телефоне.

## Ограничения текущей версии
- Записи хранятся в localStorage конкретного браузера/устройства.
- Нет синхронизации между устройствами, учётных записей и серверных резервных копий.
- Перед реальным использованием регулярно экспортируйте резервную копию в разделе «Отчёты».
